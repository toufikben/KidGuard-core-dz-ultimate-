=== (1) FORWARD direction — deviceId (owner) then geofenceId=0 (unfiltered) : WORKS ===
$ curl -s -u 'lab@example.com:REDACTED' \
    'http://127.0.0.1:8082/api/permissions?deviceId=1&geofenceId=0'
HTTP 200
[{"DEVICEID":1,"GEOFENCEID":1},{"DEVICEID":1,"GEOFENCEID":2}]

# This is the permission shape the Task 5 bootstrap relies on: rows of {OWNERKEY, PROPERTYKEY} with
# UPPERCASE keys. device 1 (lab-child-1) is linked to geofence 1 (school) AND geofence 2 (walk-to-park),
# so BOTH scenario zones are really evaluated for this device — the precondition for two geofenceExit events.

# FINDING, recorded honestly (not papered over): the geofence->device read path queries a table named
